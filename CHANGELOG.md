# Изменения

## 2.0.0-alpha.1 — 2026-11-13 (пре-релиз)

**Переписано на C# / .NET 8** — как и оригинальный K-Tools. Python-версия (1.0.0-alpha.1) сохранена
в ветке `python-legacy` и в своём релизе.

### Что изменилось
- Ядро, все 18 инструментов, калькулятор таймингов и CLI перенесены на C# один в один:
  те же параметры, ключи настроек (`settings.json` совместим), команды ffmpeg/mkvmerge и имена результатов.
- Интерфейс GTK4 + libadwaita на собственных привязках P/Invoke (без пакетов NuGet и генераторов):
  нативный Wayland, тема GTK/matugen, те же страницы и окна (дорожки, предпросмотр субтитров,
  график битрейта, синхронизация по осциллограмме, модели Whisper).
- Обработка в настоящих потоках .NET (без GIL); декодирование огибающих и корреляция — на управляемом коде без numpy.
- Сборка полностью офлайн: `make` → `dotnet publish`; PKGBUILD с `dotnet-sdk-8.0`, зависимость — `dotnet-runtime ≥ 8`.
- Встроенный дымовой тест интерфейса (`HKTOOLS_SMOKE=…`, `make smoke`) и самопроверка ядра (`make test`).
- Дочерним процессам принудительно задаётся UTF-8-локаль, если её нет (иначе mkvmerge портит не-ASCII названия).

### Проверено
- Все инструменты через CLI на тестовых файлах (ffmpeg 6.1, mkvtoolnix 82), результаты совпадают с Python-версией.
- Интерфейс под Xvfb (GTK 4.14, libadwaita 1.5): обход всех страниц, диалоги, запуск обработки.

### Не проверено / известные ограничения
- NVENC и VAAPI — не было видеокарты; аргументы те же, что в Python-версии.
- Распознавание речи и загрузка медиа — без настоящих whisper.cpp и интернета.
- Не тестировалось на реальном Arch / CachyOS / Ryoku и в сессии Hyprland.

## 1.0.0-alpha.1 — 2026-11-13 (пре-релиз)

Первая ранняя версия hktools — независимого Linux-форка [K-Tools](https://github.com/krnzhnr/k-tools).

### Что есть
- 18 инструментов оригинала + калькулятор таймингов, интерфейс на GTK4 + libadwaita.
- Видео: NVENC, VAAPI (AMD/Intel), x265, x264, SVT-AV1; вшивание надписей, автообрезка, масштаб.
- Аудио: FDK-AAC, FLAC, Opus, AC3/E-AC3 и др.; даунмикс, скорость PAL↔NTSC, разделение каналов,
  сдвиг без перекодирования (mkvmerge), пересадка с синхронизацией по осциллограмме.
- Контейнеры: сборка MKV/MP4, управление, замена и извлечение дорожек.
- Субтитры: конвертация с фильтрами и предпросмотром, сдвиг, распознавание речи (whisper.cpp).
- Загрузка через yt-dlp, анализ битрейта.
- CLI (`hktools run …`), PKGBUILD, `install.sh`, правила Hyprland (`.conf` и `.lua`), модуль Waybar,
  уведомления, интеграция с Dolphin и Thunar.

### Проверено
- Все инструменты на тестовых файлах (ffmpeg 6.1, mkvtoolnix 82) через CLI; юнит-тесты ядра.
- Интерфейс запускался в виртуальном дисплее (GTK 4.14, libadwaita 1.5).

### Не проверено / известные ограничения
- NVENC и VAAPI — не было видеокарты; команды собраны по документации ffmpeg.
- Распознавание речи — только с заглушкой вместо whisper.cpp (флаги сверены с исходниками).
- Загрузка медиа — только с локального сервера, без интернета.
- Lua-правила для Hyprland 0.55+ — синтаксис не проверен на живом Hyprland.
- Не тестировалось на реальном Arch / CachyOS / Ryoku и в сессии Hyprland.
